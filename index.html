AI Inference

The whole inference stack, not just the API call

Running open-source models yourself means owning every phase between a downloaded checkpoint and a reliable endpoint. This is how I think about it.

Select

Pick the right open model (Qwen, Gemma, Mistral, Llama) for the task, context length and license, and know when a Mixture of Experts model beats a dense one.

Fit

Size weights, KV cache and activations against GPU memory. Choose precision and quantization so the model fits a single GPU without wrecking quality.

Serve

Stand up vLLM or SGLang behind an OpenAI-compatible API on a client VM, with no external cloud dependency.

Optimize

Tune prefill vs. decode, continuous batching, prefix caching and concurrency for the latency and throughput the workload needs.

Operate

Containerize, deploy, monitor latency and GPU metrics, and wire the endpoint into agent systems on GCP and AWS.

Why self-host

Hospital and enterprise data often can't leave the network. Self-hosted inference gives clients privacy, predictable cost, and control over the model, while agents still get a standard API to call.

Why efficiency matters

My research compared Mistral 8x7B (MoE) against Llama 70B. Activating only a subset of parameters per token cuts the compute and memory traffic behind each response, which is where inference energy goes.
